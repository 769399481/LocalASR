## 复现

所有 Python 操作使用 Conda `asr`，现有 ASR / CUDA / translation 版本保持不变。

```powershell
conda run -n asr --no-capture-output python -m unittest discover -s tests -q
conda run -n asr --no-capture-output python distribution/build.py --variant optimized --phase12
```

`distribution/phase12_edit.py` 与 `phase12_strings.py` 是本次一次性迁移记录，不是日常构建步骤，不应重复执行。后续直接编辑本地化目录与相应 UI 代码。
